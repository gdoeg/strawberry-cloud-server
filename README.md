# 🍓 Strawberry Cloud Homelab

A hands-on Linux infrastructure homelab built to develop practical
skills in Linux administration, networking, security, and
troubleshooting.

## Environment

- Ubuntu Server ARM64
- Nginx web server
- SSH remote administration
- UFW host firewall
- Git/GitHub version control

## Current Services

- TCP 22 — SSH
- TCP 80 — HTTP/Nginx

## Skills Practiced

- Linux administration
- APT package management
- systemd and systemctl
- journalctl
- Linux users and groups
- File permissions and ownership
- SSH
- Nginx
- TCP/IP networking
- UFW firewall configuration
- Service troubleshooting
